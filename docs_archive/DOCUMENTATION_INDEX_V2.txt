🚀 CÁC BƯỚC KHUYÊN
================================================================================

THEO THỨ TỰ ĐỀ XUẤT:

1. Khởi động server:
   cd C:\mangadex-downloader
   uv run python .\run_web.py

2. Mở browser:
   http://localhost:8000

3. Đọc README_V2.0.txt (5 phút)

4. Thử tính năng:
   - Tab Search: "One Piece" → Thấy phân trang
   - Tab Details: Xem ID/URL
   - Tab Download: Nhập thư mục

5. Nếu cần help, đọc USAGE_GUIDE_DETAILED.txt

6. Nếu cần API, đọc API_REFERENCE.txt

================================================================================
💡 CÁCH NHANH NHẤT (3 PHÚT)
================================================================================

1. Chạy: uv run python .\run_web.py
2. Mở: http://localhost:8000
3. Search: "One Piece" → Click [Search Manga]
4. Xem: Pagination buttons ở dưới
5. Xem: ID trên mỗi card
6. Click: "View" → Xem ID đầy đủ + URL
7. Download: Paste ID → Chọn folder → Tải
8. Đã sử dụng v2.0! ✅
