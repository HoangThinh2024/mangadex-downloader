QUICK START
================================================================================

1. Run the server (if not already running):
   
   uv run python .\run_web.py

2. Open in browser:
   
   http://localhost:8000

3. Use the app:
   
   SEARCH Tab:
   - Enter manga title (e.g., "One Piece")
   - Apply filters (author, artist, status, language, rating)
   - See results with cover images
   - Click "Download" to go to download tab

   DOWNLOAD Tab:
   - Paste manga URL or ID
   - Select format (PDF, EPUB, CBZ, Raw)
   - Choose language & chapters
   - Click "Start Download"
   - Watch progress in real-time

   DETAILS Tab:
   - Enter manga ID or URL
   - Click "Load Details"
   - See full info: cover, authors, artists, chapters

================================================================================
TROUBLESHOOTING
================================================================================

Q: Search results show no images
A: Covers load from MangaDex CDN - they may take a moment

Q: Download not starting
A: Check the manga URL or ID format

Q: Status not updating
A: Refresh or check browser console for errors

Q: Mobile view broken
A: Clear browser cache and refresh (F5 or Ctrl+Shift+R)
