================================================================================
HOW TO USE
================================================================================

1. SEARCH MANGA

   - Open browser: http://localhost:8000
   - Click "Search" tab
   - Enter manga title (e.g., "One Piece")
   - (Optional) Add author, artist, status filters
   - Click "Search" button
   - View results with cover images
   - Click "Download" button to switch to download tab

2. DOWNLOAD MANGA

   - Click "Download" tab
   - Paste Manga URL or ID
   - (Optional) Select format, language, chapters
   - Click "Start Download"
   - Watch status in real-time

3. VIEW DETAILS

   - Click "Details" tab
   - Enter Manga ID or URL
   - Click "Load Details"
   - See full information, cover, authors, chapters

================================================================================
API ENDPOINTS
================================================================================

All endpoints return JSON:

GET /api/search/manga
  Parameters: title, authors, artists, status, languages, content_rating, limit
  Returns: { results: [ { id, title, status, cover, ... } ] }

POST /api/url/download
  Body: { url, save_as, language, start_chapter, end_chapter, groups, no_track }
  Returns: { job_id, ... }

GET /api/url/jobs/{job_id}
  Returns: { status, message, progress, ... }

GET /api/manga/{manga_id}
  Returns: { title, description, status, year, cover, authors, artists, ... }

GET /api/manga/{manga_id}/chapters
  Returns: { chapters: [ { chapter, title, pages, upload_date, ... } ] }
