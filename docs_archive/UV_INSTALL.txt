================================================================================
                    UV (ASTRAL PYTHON) INSTALLATION GUIDE
================================================================================

This guide shows how to install and run MangaDex Downloader Web App using
uv (Astral Python) package manager.

================================================================================
QUICK START (3 STEPS)
================================================================================

Step 1: Run installation script
--------
cd C:\mangadex-downloader
.\install-uv.ps1

Step 2: Activate virtual environment
--------
.\.venv\Scripts\Activate.ps1

Step 3: Run the web app
--------
python .\run_web.py

Then open: http://localhost:8000

================================================================================
MANUAL INSTALLATION
================================================================================

If the script doesn't work, follow these steps:

1. Install uv (if not already installed):
   
   pip install uv
   
   Or download from: https://docs.astral.sh/uv/getting-started/

2. Navigate to project:
   
   cd C:\mangadex-downloader

3. Install dependencies using uv sync:
   
   uv sync
   
   This creates .venv and installs all dependencies

4. Activate virtual environment:
   
   .\.venv\Scripts\Activate.ps1

5. Run the app:
   
   python .\run_web.py

6. Open in browser:
   
   http://localhost:8000

================================================================================
ALTERNATIVE METHODS
================================================================================

Method A: Using uv pip directly (no venv)
------------------------------------------
cd C:\mangadex-downloader
uv pip install -r requirements-uv.txt
uv run python run_web.py

Method B: Using traditional pip (if uv fails)
----------------------------------------------
cd C:\mangadex-downloader
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements-uv.txt
python run_web.py

Method C: Using pyproject.toml with uv
----------------------------------------
cd C:\mangadex-downloader
uv pip install -e .
python run_web.py

================================================================================
VERIFICATION
================================================================================

Test if installation was successful:

uv run python test_install.py

This will check all imports and show which modules are installed.

Or manually test:

uv run python -c "import fastapi; import mangadex_downloader; print('OK')"

================================================================================
RUNNING THE APP
================================================================================

Once installed, you have 3 options:

Option 1: Activate venv (Recommended)
-----
.\.venv\Scripts\Activate.ps1
python .\run_web.py

Option 2: Use uv directly (No venv activation)
-----
uv run python .\run_web.py

Option 3: With custom Python version
-----
uv run --python 3.11 python .\run_web.py

================================================================================
UV COMMANDS REFERENCE
================================================================================

uv sync                     - Create venv and install dependencies
uv sync --upgrade           - Update all packages
uv sync --fresh             - Clean reinstall
uv pip install package      - Install single package
uv pip install -r file.txt  - Install from requirements file
uv pip list                 - List installed packages
uv pip uninstall package    - Remove package
uv run python script.py     - Run script with uv environment
uv lock                      - Generate uv.lock file
uv lock --upgrade           - Update lock file

================================================================================
TROUBLESHOOTING
================================================================================

Problem: "uv: command not found"
Solution:
  pip install uv
  # Or follow: https://docs.astral.sh/uv/getting-started/

Problem: "ModuleNotFoundError" when running
Solution:
  uv sync --fresh
  # Or
  uv pip install --upgrade -r requirements-uv.txt

Problem: "Port 8000 already in use"
Solution:
  Edit run_web.py, line 3, change:
    port=8000
  to:
    port=8001

Problem: Import error with mangadex_downloader
Solution:
  Make sure you're in the project root: C:\mangadex-downloader
  Then run: uv sync

Problem: chardet or other dependency missing
Solution:
  Reinstall all dependencies:
  uv sync --upgrade

Problem: venv not activating
Solution:
  Try PowerShell directly without activation:
  uv run python .\run_web.py
