================================================================================
TROUBLESHOOTING
================================================================================

If you get errors:

1. "uv not found"
   → Install: pip install uv
   → Or: https://docs.astral.sh/uv/installation/

2. ".venv already exists"
   → Delete: Remove-Item .venv -Recurse -Force
   → Then: uv sync

3. "Module not found when running"
   → Use: uv run python .\run_web.py
   → Not: python .\run_web.py

4. Port 8000 already in use
   → Change in run_web.py: uvicorn.run(..., port=8001)
   → Or: Kill the process using port 8000
