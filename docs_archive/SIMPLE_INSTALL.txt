================================================================================
                    SIMPLE UV INSTALLATION - STEP BY STEP
================================================================================

OPTION A: AUTOMATIC (Simplest)
================================================================================

Open PowerShell in C:\mangadex-downloader and run:

    .\install-uv.ps1

That's it! The script handles everything.

Then start the app:
    
    .\.venv\Scripts\Activate.ps1
    python .\run_web.py

Open browser: http://localhost:8000

================================================================================
OPTION B: MANUAL (If script doesn't work)
================================================================================

Step 1: Ensure uv is installed
------
PS C:\mangadex-downloader> pip install uv
# or download from https://astral.sh/uv


Step 2: Create environment and install dependencies
------
PS C:\mangadex-downloader> uv sync

# Or if you want to upgrade:
PS C:\mangadex-downloader> uv sync --upgrade


Step 3: Activate the virtual environment
------
PS C:\mangadex-downloader> .\.venv\Scripts\Activate.ps1

# If that fails, try:
PS C:\mangadex-downloader> .\.venv\Scripts\Activate


Step 4: Run the web app
------
(venv) PS C:\mangadex-downloader> python .\run_web.py

# Or without activating:
PS C:\mangadex-downloader> uv run python .\run_web.py


Step 5: Open in browser
------
http://localhost:8000

================================================================================
OPTION C: FROM REQUIREMENTS FILE (Fallback)
================================================================================

If uv sync doesn't work:

Step 1: Create virtual environment
------
PS C:\mangadex-downloader> python -m venv venv


Step 2: Activate
------
PS C:\mangadex-downloader> .\venv\Scripts\Activate.ps1


Step 3: Install with uv
------
(venv) PS C:\mangadex-downloader> uv pip install -r requirements-uv.txt

# Or with pip if uv fails:
(venv) PS C:\mangadex-downloader> pip install -r requirements-uv.txt


Step 4: Run
------
(venv) PS C:\mangadex-downloader> python .\run_web.py

================================================================================

================================================================================
USING THE APP
================================================================================

Once running on http://localhost:8000:

1. SEARCH:
   - Type "One Piece" in search box
   - Click a result to fill URL
   
2. DOWNLOAD:
   - URL should be populated
   - Click "Download" button
   
3. WATCH STATUS:
   - Status updates every 1.5 seconds
   - Shows: queued → running → done

4. API (PowerShell):
   
   # Search
   Invoke-RestMethod -Uri "http://localhost:8000/api/search/manga?q=one+piece"
   
   # Start download
   $job = Invoke-RestMethod -Uri "http://localhost:8000/api/url/download" `
     -Method Post -ContentType "application/json" `
     -Body (@{url='https://mangadex.org/title/...'} | ConvertTo-Json)
   
   # Check status
   Invoke-RestMethod -Uri "http://localhost:8000/api/url/jobs/$($job.job_id)"

================================================================================
QUICK REFERENCE
================================================================================

Essential Commands:
  
  uv sync                        Install everything
  .\.venv\Scripts\Activate.ps1   Activate venv
  python .\run_web.py            Run app
  uv run python ...              Run without activating
  uv pip install package         Install a package
  uv pip list                    Show installed packages
  uv run python test_install.py  Test installation

Common Issues:

  Issue: uv not found
  Fix:   pip install uv
  
  Issue: Port in use
  Fix:   Edit run_web.py, change port=8000 to port=8001
  
  Issue: Module not found
  Fix:   uv sync --fresh
  
  Issue: Can't activate venv
  Fix:   Use: uv run python .\run_web.py (no activation needed)
