USE REST API (PowerShell):

  # Search
  Invoke-RestMethod -Uri "http://localhost:8000/api/search/manga?q=one+piece"

  # Download
  $job = Invoke-RestMethod -Uri "http://localhost:8000/api/url/download" `
    -Method Post -ContentType "application/json" `
    -Body (@{url='https://mangadex.org/title/...'} | ConvertTo-Json)

  # Check status
  Invoke-RestMethod -Uri "http://localhost:8000/api/url/jobs/$($job.job_id)"

================================================================================
TROUBLESHOOTING
================================================================================

PROBLEM: "uv: command not found"
FIX: pip install uv

PROBLEM: "ModuleNotFoundError" on import
FIX: uv sync --fresh

PROBLEM: Port 8000 already in use
FIX: Edit run_web.py, change port=8000 to port=8001

PROBLEM: Can't activate venv
FIX: Use: uv run python .\run_web.py (no activation needed)

PROBLEM: Dependencies missing after install
FIX: uv sync --upgrade

PROBLEM: Installation hangs
FIX: Use: uv pip install --upgrade -r requirements-uv.txt

For more help, see: UV_INSTALL.txt or START_HERE.txt
