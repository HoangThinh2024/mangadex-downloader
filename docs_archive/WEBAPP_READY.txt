================================================================================
API ENDPOINTS AVAILABLE
================================================================================

GET /api/search/manga
  Search manga with filters

POST /api/url/download
  Start download job

GET /api/url/jobs/{id}
  Get download status

GET /api/manga/{id}
  Get manga details

GET /api/manga/{id}/chapters
  Get chapter list

GET /api/covers/manga/{id}
  Get cover images

GET /api/groups/{id}
  Get group info

GET /api/authors/{id}
  Get author info

================================================================================
SUPPORT & TROUBLESHOOTING
================================================================================

Server won't start?
  → Make sure port 8000 is free
  → Try: uv sync first

No search results?
  → Check internet connection
  → Try different keywords

Images not loading?
  → Wait a moment (CDN loading)
  → Refresh browser (F5)

Download not working?
  → Check manga URL/ID format
  → Verify URL is from mangadex.org
