================================================================================
                    QUICK START GUIDE
================================================================================

This is the fastest way to get the MangaDex Downloader Web App running.


================================================================================
ONE COMMAND SETUP
================================================================================

```powershell
uv sync && uv run python .\run_web.py
```

Then open: http://localhost:8000

Done! 🎉


================================================================================
STEP BY STEP
================================================================================

1. INSTALL DEPENDENCIES

   ```powershell
   uv sync
   ```

   This will:
   - Create virtual environment at .venv/
   - Install all 67 dependencies
   - Setup project


2. RUN THE WEBAPP

   ```powershell
   uv run python .\run_web.py
   ```

   This will:
   - Start FastAPI server
   - Listen on http://localhost:8000
   - Show: "Uvicorn running on http://0.0.0.0:8000"


3. OPEN IN BROWSER

   Navigate to:
   - Main UI: http://localhost:8000
   - Swagger Docs: http://localhost:8000/docs
   - ReDoc: http://localhost:8000/redoc


4. USE THE APP

   - Search Tab: Search manga with filters
   - Download Tab: Download with options
   - Details Tab: View manga information

================================================================================
TROUBLESHOOTING
================================================================================

Q: "uv: command not found"
A: Install uv first:
   pip install uv
   OR
   https://docs.astral.sh/uv/installation/


Q: Port 8000 already in use
A: Change port in run_web.py:
   uvicorn.run(app, host="0.0.0.0", port=8001)


Q: Module import errors
A: Make sure you're using:
   uv run python .\run_web.py
   NOT:
   python .\run_web.py


Q: Virtual environment issues
A: Delete and recreate:
   Remove-Item .venv -Recurse -Force
   uv sync

================================================================================
DEVELOPMENT
================================================================================

If you want to modify the code:

1. Edit files in webapp/
2. Server auto-reloads on save
3. Check console for errors
4. Refresh browser to see changes


================================================================================
DEPLOYMENT
================================================================================

For production use:

1. Comment out auto-reload in run_web.py:
   uvicorn.run(app, host="0.0.0.0", port=8000, reload=False)

2. Use a process manager (Gunicorn, etc):
   gunicorn webapp.app:app
