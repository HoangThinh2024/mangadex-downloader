USING THE WEB APP
================================================================================

Web Interface (http://localhost:8000):

1. SEARCH FOR MANGA
   - Type title in search box (e.g., "One Piece")
   - Click search button
   - Results appear in dropdown
   - Click a result to select it

2. DOWNLOAD MANGA
   - URL is auto-filled from search
   - Or paste your own URL
   - Click "Download" button
   - Job queued immediately (unique ID shown)

3. MONITOR PROGRESS
   - Status updates every 1.5 seconds
   - Shows: queued → running → done/error
   - Error messages show below

4. ADVANCED OPTIONS (API)
   - Format: cbz, pdf, epub, raw, 7z
   - Path: custom download location
   - Log Level: DEBUG, INFO, WARNING, ERROR
   - Tracking: enable/disable download tracker

================================================================================
API ENDPOINTS (REST)
================================================================================

Health Check:
  GET /health
  Response: OK

Home Page:
  GET /
  Response: HTML web interface

Search Manga:
  GET /api/search/manga?q=one+piece&limit=10
  Response: {
    "results": [
      { "id": "...", "title": "...", "status": "...", ... }
    ]
  }

Download (with options):
  POST /api/url/download
  Body: {
    "url": "https://mangadex.org/title/...",
    "save_as": "cbz",           (optional)
    "path": "C:\\downloads",    (optional)
    "log_level": "INFO",        (optional)
    "no_track": false           (optional)
  }
  Response: { "job_id": "abc123..." }

Check Job Status:
  GET /api/url/jobs/{job_id}
  Response: {
    "job_id": "abc123",
    "status": "queued|running|done|error",
    "message": "..."
  }

Get Configuration:
  GET /api/config
  Response: {
    "save_as": "raw",
    "path": ".",
    "no_track": false,
    "log_level": "INFO"
  }

Update Configuration:
  PUT /api/config
  Body: {
    "save_as": "cbz",
    "path": "C:\\downloads"
  }
  Response: { "status": "ok" }

================================================================================
TROUBLESHOOTING
================================================================================

PROBLEM: "uv: command not found"
SOLUTION:
  pip install uv
  # or follow https://docs.astral.sh/uv/getting-started/

PROBLEM: "ModuleNotFoundError: No module named 'chardet'"
SOLUTION:
  uv sync --fresh
  # or
  uv pip install --upgrade -r requirements-uv.txt

PROBLEM: "Port 8000 already in use"
SOLUTION:
  Edit run_web.py, find: port=8000
  Change to: port=8001 (or any unused port)
  Then restart: python .\run_web.py

PROBLEM: Virtual environment won't activate
SOLUTION:
  Use uv directly without activating:
  uv run python .\run_web.py

PROBLEM: Some modules still missing after install
SOLUTION:
  Completely reinstall:
  uv sync --fresh
  # or
  rm -r .venv
  uv sync

PROBLEM: Dependencies conflict
SOLUTION:
  Update lock file:
  uv lock --upgrade
  uv sync

PROBLEM: App crashes on startup
SOLUTION:
  Check logs for errors, verify imports:
  uv run python test_install.py

Pip (Install packages):

Lock (Manage versions):
  uv lock                 (generate lock file)
  uv lock --upgrade       (update dependencies)

Run (Execute without activating):
  uv run python script.py
  uv run --python 3.11 python script.py
