🔌 API ENDPOINTS BY CATEGORY
================================================================================

SEARCH (6 endpoints)
  GET /api/search/manga           Advanced manga search
  GET /api/search/authors         Search authors
  GET /api/search/artists         Search artists

MANGA (3 endpoints)
  GET /api/manga/{id}             Get manga details
  GET /api/manga/{id}/chapters    Get chapter list
  GET /api/manga/{id}/feed        Get latest chapters

COVERS (2 endpoints)
  GET /api/covers/manga/{id}      Get manga covers
  GET /api/covers/{id}/image      Get specific cover

PEOPLE (5 endpoints)
  GET /api/groups/{id}            Get group info
  GET /api/groups                 List groups
  GET /api/authors/{id}           Get author info
  GET /api/artists/{id}           Get artist info
  GET /api/manga/{id}/groups      Get manga groups

DOWNLOAD (2 endpoints)
  POST /api/url/download          Start download
  GET /api/url/jobs/{id}          Check status

CONFIG (2 endpoints)
  GET /api/config                 Get configuration
  PUT /api/config                 Update configuration

UTILITY (1 endpoint)
  GET /health                     Health check

See WEBAPP_API_FULL.md for complete documentation

❓ FREQUENT QUESTIONS
================================================================================

Q: How do I start?
A: Run .\install-uv.ps1 then python .\run_web.py
   See: SIMPLE_INSTALL.txt

Q: What if uv is not installed?
A: Use traditional pip with venv
   See: SIMPLE_INSTALL.txt (Option C)

Q: How do I search with filters?
A: Use Search tab in UI or /api/search/manga endpoint
   See: WEBAPP_API_FULL.md

Q: How do I download a manga?
A: Use Download tab or POST /api/url/download
   See: WEBAPP_API_FULL.md

Q: How do I track download progress?
A: Use GET /api/url/jobs/{job_id}
   See: WEBAPP_API_FULL.md

Q: How do I get manga details?
A: Use Details tab or GET /api/manga/{id}
   See: WEBAPP_API_FULL.md

Q: What API endpoints are available?
A: See: WEBAPP_API_FULL.md (25+ endpoints)

Q: Can I use this from my code?
A: Yes! See: WEBAPP_API_FULL.md "Examples" (Python, PowerShell, etc)

Q: Is it mobile-friendly?
A: Yes, fully responsive design

Q: What formats can I download?
A: PDF, EPUB, CBZ, RAW (JPG/PNG), 7ZIP

Q: Can I filter by language?
A: Yes, search has language filter, download too

Q: Can I download specific chapters?
A: Yes, specify start/end chapter in download options
