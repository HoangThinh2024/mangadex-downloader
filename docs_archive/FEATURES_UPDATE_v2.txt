TÍNH NĂNG MỚI ĐƯỢC THÊM VÀO
================================================================================

✅ 1. TÍNH NĂNG PHÂN TRANG (PAGINATION)
   - Hỗ trợ phân trang trong tìm kiếm
   - Có thể chọn số lượng kết quả mỗi trang (1-100)
   - Hiển thị tổng số truyện tìm thấy (ví dụ: 95 kết quả cho "One Piece")
   - Nút Previous/Next để duyệt trang
   - Có thể nhảy đến trang cụ thể
   - Hiển thị "Page X of Y"
   
   API: 
   - GET /api/search/manga?title=...&limit=12&offset=0
   - offset = trang * limit (để tính vị trí bắt đầu)

✅ 2. HIỂN THỊ URL / ID CỦA TRUYỆN
   - Mỗi card truyện hiển thị ID rút gọn (8 ký tự đầu)
   - Click vào "View Details" để xem ID đầy đủ
   - Tab Details hiển thị:
     * Manga ID (đầy đủ) - copy được
     * Manga URL: https://mangadex.org/title/{id}
     * Có link trực tiếp đến MangaDex

✅ 3. CHỨC NĂNG CHỌN THƯ MỤC TẢI XUỐNG
   - Thêm field "Save Directory" vào Download Form
   - Có thể nhập đường dẫn thư mục để lưu file
   - Nếu để trống sẽ dùng đường dẫn mặc định của app
   - Hỗ trợ cả đường dẫn tuyệt đối (C:\...) và tương đối

✅ 4. TỈM KIẾM THEO TÁC GIẢ (AUTHOR)
   - Thêm field "Author (Search)" để tìm kiếm theo tác giả
   - Hoạt động cùng với các bộ lọc khác
   - Ví dụ: Tìm kiếm "Naruto" + tác giả "Masashi Kishimoto"

✅ 5. TÌM KIẾM THEO HỌA SĨ (ARTIST)
   - Thêm field "Artist (Search)" để tìm kiếm theo họa sĩ
   - Hoạt động độc lập hoặc kết hợp với các bộ lọc khác
   - Giúp tìm truyện theo người vẽ cụ thể

================================================================================
CẬP NHẬT API (BACKEND)
================================================================================

📍 GET /api/search/manga
   Parameters:
   - title (string, required): Tên truyện cần tìm
   - authors (string, optional): Tên tác giả
   - artists (string, optional): Tên họa sĩ
   - status (string, optional): ongoing, completed, hiatus, cancelled
   - languages (string, optional): Mã ngôn ngữ (ja, en, zh, ko, ...)
   - content_rating (string, optional): safe, suggestive, erotica, pornographic
   - limit (int, default=12, max=100): Số lượng kết quả trả về
   - offset (int, default=0): Vị trí bắt đầu (dùng cho phân trang)

   Response:
   {
     "results": [
       {
         "id": "manga-id",
         "title": "Manga Title",
         "status": "ongoing",
         "originalLanguage": "ja",
         "year": 1997,
         "cover": "https://uploads.mangadex.org/covers/..."
       }
     ],
     "total": 95,           // ← Tổng số kết quả (MỚI)
     "limit": 12,           // ← Giới hạn mỗi trang (MỚI)
     "offset": 0            // ← Vị trí hiện tại (MỚI)
   }

📍 GET /api/search/languages (MỚI)
   Lấy danh sách tất cả 39 ngôn ngữ được hỗ trợ
   Response:
   {
     "languages": [
       {"code": "en", "name": "English"},
       {"code": "ja", "name": "Japanese"},
       ...
     ]
   }

📍 GET /api/search/authors (MỚI)
   Tìm kiếm tác giả
   Parameters: query (string)
   Response:
   {
     "authors": [
       {"id": "author-id", "name": "Author Name"}
     ]
   }

📍 GET /api/search/artists (MỚI)
   Tìm kiếm họa sĩ
   Parameters: query (string)
   Response:
   {
     "artists": [
       {"id": "artist-id", "name": "Artist Name"}
     ]
   }

CÁCH SỬ DỤNG MỚI
================================================================================

1️⃣ TÌMM KIẾM BASIC:
   - Nhập tên truyện (bắt buộc)
   - Chọn số kết quả mỗi trang
   - Click "Search Manga"
   - Duyệt qua các trang bằng pagination buttons

2️⃣ TÌMM KIẾM NÂNG CAO:
   - Tên truyện + Tác giả → Tìm truyện của tác giả cụ thể
   - Tên truyện + Họa sĩ → Tìm truyện được vẽ bởi người cụ thể
   - Tên truyện + Ngôn ngữ → Tìm truyện gốc từ nước cụ thể
   - Tên truyện + Status → Tìm truyện đang tiếp diễn hoặc hoàn thành
   - Kết hợp tất cả các bộ lọc trên

3️⃣ XEM CHI TIẾT TRUYỆN:
   - Click "View" trên card truyện, HOẶC
   - Tab "Details" → nhập ID/URL → "Load Details"
   - Kết quả: ID, URL, Cover, Authors, Artists, Chapters

4️⃣ TẢI XUỐNG TRUYỆN:
   - Tab "Download" → Paste URL hoặc ID
   - Chọn Format (PDF, EPUB, CBZ, Raw)
   - Chọn Ngôn ngữ
   - Nhập Chapter Range (tùy chọn)
   - Nhập Save Directory (hoặc để trống)
   - Click "Start Download"
