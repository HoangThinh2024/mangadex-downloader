✅ TẤT CẢ ĐÃ ĐƯỢC THỰC HIỆN
================================================================================

1. ✅ CHỨC NĂNG CHỌN THƯ MỤC TẢI XUỐNG
   - Thêm field "Save Directory" trong Download form
   - Người dùng có thể nhập đường dẫn: C:\Manga\
   - Để trống = dùng default directory

2. ✅ TÍNH NĂNG CHUYỂN PAGE (PHÂN TRANG)
   - API hỗ trợ offset + limit
   - UI có pagination buttons: Previous [1] [2] [3]... Next
   - Ví dụ "One Piece" → 95 kết quả, phân trang từng 12
   - Có thể chọn 1-100 kết quả mỗi trang

3. ✅ HIỂN THỊ URL / ID
   - Mỗi card tìm kiếm: Hiển thị ID rút gọn (8 ký tự)
   - Tab Details: Hiển thị ID đầy đủ + URL https://mangadex.org/title/{id}
   - Có thể copy ID dễ dàng

4. ✅ TÌM KIẾM THEO AUTHOR
   - Thêm field "Author (Search)" trong search tab
   - Ví dụ: "Naruto" + "Masashi Kishimoto"
   - API fully support

5. ✅ TÌM KIẾM THEO ARTIST
   - Thêm field "Artist (Search)" trong search tab
   - Hoạt động độc lập hoặc kết hợp

     Nepali, Norwegian, Odia, Punjabi, Romanian, Slovak, Slovenian, Somali,
     Serbian, Swedish, Tamil, Telugu, Filipino, Urdu, Uzbek, Chinese (Romanized)

7. ✅ LẤY TOÀN BỘ DỮ LIỆU MANGADEX

   - Mỗi trang max 100 kết quả
