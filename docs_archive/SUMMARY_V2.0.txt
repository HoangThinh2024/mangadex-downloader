✅ TẤT CẢ TÍNH NĂNG CẦN CẸ ĐÃ HOÀN THÀNH
================================================================================

1. ✅ PHÂN TRANG (PAGINATION)
   - Hỗ trợ phân trang: offset, limit
   - Xem 1-100 kết quả mỗi trang
   - Hiển thị tổng số (ví dụ: 95 kết quả One Piece)
   - UI: Nút Previous/Next, jump to page
   - API: /api/search/manga?title=...&limit=12&offset=0

2. ✅ HIỂN THỊ URL / ID
   - Manga ID: Hiển thị rút gọn trên card (8 ký tự)
   - Tab Details: Hiển thị ID đầy đủ + URL https://mangadex.org/title/{id}
   - Có thể copy ID để dùng ở Download tab

3. ✅ CHỌN THƯ MỤC TẢI XUỐNG
   - Thêm field "Save Directory" vào Download form
   - Có thể nhập đường dẫn (C:\Manga\)
   - Để trống = dùng default

4. ✅ TÌM KIẾM THEO TÁC GIẢ (AUTHOR)
   - Field "Author (Search)" trong search form
   - Kết hợp với Title tìm chính xác
   - API: /api/search/manga?title=naruto&authors=Masashi

5. ✅ TÌM KIẾM THEO HỌA SĨ (ARTIST)
   - Field "Artist (Search)" trong search form
   - Độc lập hoặc kết hợp các bộ lọc
   - API: /api/search/manga?title=...&artists=...

6. ✅ TOÀN BỘ NGÔN NGỮ MANGADEX (39 NGÔN NGỮ)
   - Từ English đến Vietnamese, Thai, Korean, Arabic...
   - Dropdown trong search form
   - API endpoint: /api/search/languages

7. ✅ LẤY TOÀN BỘ DỮ LIỆU MANGADEX
   - Phân trang cho phép duyệt tất cả truyện
   - Mỗi trang max 100 kết quả
   - Tổng số kết quả trả về từ API
   - Chỉ đọc (không upload)

❓ CÂUHỎI THƯỜNG GẶP
================================================================================

Q: Có thể tìm kiếm tất cả truyện không?
A: Có, dùng phân trang + offset/limit. Mỗi trang 100 kết quả.

Q: Directory selection có GUI file picker không?
A: Hiện tại là text field. GUI picker cần backend hỗ trợ.

Q: 39 ngôn ngữ ở đâu?
A: Dropdown "Original Language" trong Search tab.

Q: Phân trang hoạt động như thế nào?
A: limit=số kết quả/trang, offset=vị trí bắt đầu.
   Page 1: offset=0, Page 2: offset=limit, Page 3: offset=limit*2

Q: Tại sao không tải được?
A: Kiểm tra ID/URL đúng, thư mục có quyền, format hỗ trợ.
