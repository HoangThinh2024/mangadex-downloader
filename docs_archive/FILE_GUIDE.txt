QUICK REFERENCE
════════════════════════════════════════════════════════════════════════════

Installation:
  Automatic:  .\install-uv.ps1
  uv sync:    uv sync && .\.venv\Scripts\Activate.ps1 && python .\run_web.py
  Direct:     uv run python .\run_web.py
  Pip:        python -m venv venv && .\venv\Scripts\Activate.ps1 && pip install -r requirements-uv.txt

Run:
  python .\run_web.py              (after activation)
  uv run python .\run_web.py      (without activation)

Test:
  python test_install.py           (verify all imports)

Access:
  Web UI:     http://localhost:8000
  API Docs:   http://localhost:8000/docs
  ReDoc:      http://localhost:8000/redoc
