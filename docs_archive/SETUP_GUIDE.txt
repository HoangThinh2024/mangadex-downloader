================================================================================

Search:

  GET /api/config

  Body: { "save_as": "cbz", "path": "downloads" }

  # Check status

FastAPI Web App Structure:

  │   - SessionMiddleware (signed cookies)

## HOW IT WORKS
================================================================================

1. SEARCH FLOW
   User types "One Piece" → Web form sends GET /api/search/manga?q=one+piece
   → Router queries MangaDex API → Returns results
   → User clicks result → URL populated in download form

2. DOWNLOAD FLOW
   User clicks "Download" → POST /api/url/download with URL + options
   → Router generates UUID job_id
   → Queues asyncio.create_task(_run(job_id, request))
   → Returns job_id immediately
   → Background task runs mangadex_downloader.cli.main(argv) in thread executor
   → Job status updates: queued → running → done/error
   → UI polls GET /api/url/jobs/{job_id} every 1.5 seconds
   → Status shown in real-time

3. CONFIGURATION FLOW
   User calls GET /api/config → Reads current mangadex_downloader config
   User calls PUT /api/config with updates → CLI builds new config and persists

## TROUBLESHOOTING
================================================================================

Issue: ModuleNotFoundError when running
Fix: uv pip install -r .\requirements-uv.txt

Issue: Port 8000 already in use
Fix: Edit run_web.py line 3, change port=8000 to port=8001

Issue: Search returns 404
Fix: Ensure app.py imports are at module level (no try/except)

Issue: Download not starting
Fix: Check MangaDex URL format is https://mangadex.org/title/{uuid}

Issue: Downloaded files in wrong location
Fix: Use /api/config PUT endpoint to set "path" option
