USING THE ENHANCED APP
================================================================================

1️⃣  INSTALLATION (No changes needed)
──────────────────────────────────────────────────────────────────────────────
.\install-uv.ps1
or
uv sync && .\.venv\Scripts\Activate.ps1


2️⃣  START SERVER
──────────────────────────────────────────────────────────────────────────────
python .\run_web.py

→ Open: http://localhost:8000


3️⃣  USE THE APP

   Search Tab:
   ───────────
   • Type manga title
   • Use filters for advanced search
   • Click "Search" button
   • Browse results in grid
   • Click download for any result

   Download Tab:
   ─────────────
   • Paste manga URL (or use search tab)
   • Choose format, language, chapters
   • Click "Start Download"
   • Watch real-time progress

   Details Tab:
   ───────────
   • Paste manga ID or URL
   • Click "Load Details"
   • View full information
   • See latest chapters


4️⃣  API USAGE

   PowerShell:
   ───────────
   $search = Invoke-RestMethod "http://localhost:8000/api/search/manga?title=one+piece"
   $search.data | Format-Table title, status

   Python:
   ───────
   import requests
   res = requests.get("http://localhost:8000/api/search/manga", 
                      params={"title": "One Piece", "limit": 10})
   print(res.json())

FEATURES REFERENCE
================================================================================

SEARCH MANGA
────────────
GET /api/search/manga?title=one&status=ongoing&content_rating=safe&limit=10

Available Filters:
  title              - Manga title (string)
  authors            - Author IDs (array)
  artists            - Artist IDs (array)
  year               - Publication year (int)
  status             - ongoing|completed|hiatus|cancelled
  languages          - Language codes (array: en, ja, zh, ko, etc)
  tags               - Include tags (array of tag IDs)
  excluded_tags      - Exclude tags (array of tag IDs)
  content_rating     - safe|suggestive|erotica|pornographic
  limit              - 1-100 results (default: 10)
  offset             - Pagination offset (default: 0)


GET MANGA DETAILS
─────────────────
GET /api/manga/550537c6-43a3-404a-ab36-8f359068fb00

Returns:
  - Full manga info

  - Alt titles


GET CHAPTERS
────────────

  - Scanlation groups
